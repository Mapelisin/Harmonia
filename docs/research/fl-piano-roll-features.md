# Piano Roll FL Studio — функциональный каталог для Harmonia

## 0. Введение

**Что это.** Piano Roll в FL Studio — редактор нот и автоматизации одного канала-инструмента внутри Pattern.
Высота звука идёт по вертикали (слева клавиатура), время — по горизонтали (сверху линейка тактов),
ноты — прямоугольные полосы. Нижняя панель (Event editor) показывает свойства нот («леденцы»)
или кривые автоматизации. Ноты хранятся в Pattern; Pattern расставляется в Playlist клипами.
Piano roll умеет показывать ноты других каналов и других клипов как ghost notes.

**Источник.** Официальное онлайн-руководство Image-Line (FL Studio Online Manual), актуальная версия —
**FL Studio 2026** (на странице What's New последнее обновление 2026.1.7 от 28.09.2026), плюс страницы
What's New для 2024 / 2025 / 2026. Дата составления: **2026-11-08**.
Здесь описано только поведение, своими словами. Графику, иконки и тексты FL не копируем.

**Обозначения.**
- **[P1]** — нужно в первой версии (ежедневная работа битмейкера).
- **[P2]** — важно, сразу после первой версии.
- **[P3]** — продвинутое, можно позже.
- *(unverified)* — в руководстве не описано или описано неоднозначно; перед реализацией проверить в самой FL.
- ЛКМ / ПКМ / СКМ — левая / правая / средняя кнопка мыши. Ctrl = Cmd, Alt = Opt на macOS.
- FL различает **левый и правый** Shift и Alt (у них разные функции).
- Одиночные клавиши-хоткеи работают, только когда выключен Typing keyboard to piano.

## 1. Базовое редактирование нот

### 1.1 Инструменты панели (edit tools)
- [P1] **Draw (P)** — ЛКМ по пустому месту ставит ноту текущей длины; пока кнопка зажата, ноту можно довести до нужной позиции и высоты.
- [P1] **Draw: ПКМ** — ПКМ по ноте удаляет её; ПКМ-протяжка удаляет все задетые ноты.
- [P1] **Draw + Left-Shift** — протяжка ЛКМ сразу задаёт длину новой ноты (режим «растягивания»).
- [P1] **Draw + Ctrl** — временно включает выделение рамкой.
- [P2] **Draw + Alt** — ставит ноту без привязки к сетке.
- [P3] **Draw: удержание ПКМ на пустом фоне** — вызывает нож (slice); работает, если включено в General settings.
- [P1] **Paint (B)** — протяжка ЛКМ «рисует» цепочку нот с шагом текущей длины; можно рисовать над/под существующими, получая аккорды; ПКМ удаляет.
- [P2] **Paint + Shift (monophonic paint)** — можно вести мышь вверх-вниз, новые ноты заменяют существующие в этом месте; в настройках можно сделать монофонию поведением по умолчанию.
- [P2] **Paint drum sequencer mode (N)** — Paint для ударных: клик по существующей ноте включает/выключает её mute, длина ноты = snap; Alt рисует с половиной snap; ПКМ удаляет.
- [P1] **Delete (D)** — клик или протяжка удаляют ноты; Ctrl — выделить, затем Del.
- [P2] **Mute (T)** — клик/протяжка глушат или включают ноты (нота остаётся, но не звучит); ПКМ удаляет.
- [P1] **Slice (C)** — протяжкой рисуется линия разреза; все пересечённые ноты режутся в точке пересечения.
- [P2] **Slice: модификаторы** — Shift режет кликом без протяжки, Shift+Alt — то же без snap, Ctrl — выделение.
- [P1] **Select (E)** — режим выделения без удержания Ctrl; Shift добавляет или убирает ноты.
- [P2] **Zoom (Z)** — рамка ЛКМ приближает область, клик по фону отдаляет, ПКМ переключает zoom/unzoom.
- [P2] **Play selected / scrub (Y)** — клик по нотам проигрывает их, протяжка «прослушивает» по времени.
- [P3] **Interpolate (I)** — только для настоящих event-данных в нижней панели: протяжкой превращает ступеньки в линейный переход; на свойствах нот не работает.
- [P3] **Смена инструмента колесом** — зажать ПКМ и крутить колесо, перебирая инструменты.
- [P2] **Context Tool-Menu** — СКМ + ПКМ открывает под курсором меню инструментов и главное меню piano roll.

### 1.2 Перемещение, длина, жесты (в инструментах рисования)
- [P1] **Перетаскивание ноты** — двигает по времени и высоте; по горизонтали подчиняется snap.
- [P1] **Alt при перетаскивании** — временно отключает snap (точность — тик PPQ).
- [P1] **Правый край ноты** — изменение длины (курсор меняется на двустороннюю стрелку).
- [P2] **Левый край ноты** — изменение начала при сохранении конца; только при включённой опции Allow resizing from left (Ctrl+Alt+Home).
- [P2] **Фиксация оси** — нажать на ноту, затем Shift+движение по горизонтали сохраняет высоту; Ctrl+движение по вертикали сохраняет время.
- [P1] **Shift+перетаскивание выделения** — копия (clone) выделенных нот.
- [P1] **Двойной клик по ноте** — диалог Note properties (см. раздел 4).
- [P1] **Длина новой ноты** — берётся из последней ноты, по которой кликнули, или из настройки ПКМ по иконке snap.
- [P2] **Click-and-hold на ноте** — копирует ноту (жест включается в F10 > General).
- [P2] **Click-and-hold на стыке двух соседних нот** — склеивает их (glue).
- [P3] **Click-and-hold при добавлении ноты** — перебирает режимы slide/porta для новой ноты.
- [P3] **Snap note sides** — жест привязки краёв ноты к сетке *(детали unverified)*.
- [P2] **Right-Shift + ЛКМ** — разрезать ноту в точке клика; **Right-Shift + ПКМ** — разрезать и удалить меньший кусок.
- [P3] **Left-Shift + протяжка по точке разреза / правому краю аккорда** — меняет длины частей или аккорда целиком *(точная семантика unverified)*.
- [P2] **Left-Alt + ПКМ** — прослушивание (scrub) прямо в режиме Draw.
- [P3] **Right-Alt + ПКМ** — квантовать выделенное.

### 1.3 Выделение
- [P1] **Ctrl+клик / Ctrl+рамка** — выделить; Ctrl+Shift — добавить к выделению или убрать отдельные ноты.
- [P1] **Снять выделение** — Ctrl+клик по пустому месту или Ctrl+D; **Ctrl+A** — выделить всё.
- [P1] **Временной диапазон** — Ctrl+клик или двойной клик по линейке времени и протяжка.
- [P2] **Диапазон высот** — Ctrl+клик или вертикальная протяжка по клавиатуре слева.
- [P2] **Invert selection (Shift+I)** — поменять выделенное и невыделенное.
- [P2] **Select by color (Shift+C)** — выделить ноты текущего цвета.
- [P2] **Select muted** — выделить заглушённые ноты.
- [P2] **Select time around selection (Ctrl+Enter)** — временной диапазон по границам выделенных нот; Ctrl+←/→ сдвигает диапазон на его ширину.
- [P3] **Случайный выбор** — Shift+R / Shift+M (одна или ещё несколько случайных нот).
- [P3] **Select odd (Shift+O)** — ноты вне основной сетки (свингованные).
- [P3] **Select overlapping / Select stacked notes** — все, кроме нижней, среди перекрывающихся / полностью совпадающих (поиск дублей).
- [P3] **Magic lasso** — выделение обводкой курсора без нажатия кнопок.

### 1.4 Группы нот
- [P2] **Group (Shift+G)** — связать выделенные ноты: действие с одной нотой применяется ко всей группе; групп может быть много.
- [P2] **Ungroup (Alt+G)** — разгруппировать.
- [P2] **Переключатель grouping на тулбаре** — временно отключает группы, чтобы править отдельные ноты.
- [P2] **Автогруппировка** — Chop, Arpeggiate, Flam, Chord Progression умеют группировать созданные ими ноты.

### 1.5 Растяжение (stretch)
- [P2] **Ручка stretch у выделения** — растягивает/сжимает позиции и длины нот; с FL 2026 по умолчанию с привязкой к snap, Alt — без.
- [P3] **Right-Shift + правый край ноты в выделении** — то же растяжение; Alt+Right-Shift — шагами по 25%.

### 1.6 Правка с клавиатуры и колесом
- [P1] **Shift+←/→** — сдвиг на шаг snap; **Shift+↑/↓** — на полутон; **Ctrl+↑/↓** — на октаву.
- [P2] **Alt+стрелки** — сдвиг на шаг в пикселях (зависит от масштаба).
- [P2] **Shift+Alt+колесо над нотами** — сдвиг нот под курсором; опция Nudge notes with mouse wheel переносит это на Shift+колесо.
- [P2] **Rotate left/right (Shift+Ctrl+←/→)** — циклический сдвиг внутри такта(ов): вышедшее за край возвращается с другой стороны.

## 2. Snap и сетка

- [P1] **Локальный Snap piano roll** — значения: Main, Line, Cell, (none), доли шага 1/6…1 step, доли доли 1/6…1 beat, Bar, Events, Markers.
- [P1] **Main / Global Snap** — общий snap на панели FL; используется Piano roll, Playlist и Event editor, если у них выбран Main.
- [P1] **Line / Cell** — Line: к ближайшей линии сетки (зависит от zoom); Cell: к началу ячейки.
- [P1] **(none)** — без привязки, точность ограничена PPQ.
- [P1] **Соответствие длительностям** — 1/4 step = 1/64, 1/2 step = 1/32, 1/4 beat = 1/16, 1/3 beat = триоль, 1/2 beat = 1/8, beat = 1/4, bar = целая.
- [P1] **Alt (удержание)** — временно snap = none при перетаскивании.
- [P1] **Сетка** — линии тактов, долей и шагов; густота зависит от горизонтального zoom.
- [P2] **Events** — привязка к краям существующих нот, включая ghost notes (удобно для нарезанных «встык» нот).
- [P3] **Markers** — привязка к Time markers.
- [P2] **Backspace** — включить/выключить глобальный snap.
- [P2] **Snap и запись** — глобальный snap квантует MIDI-вход при записи (кроме (none), Line, Cell).
- [P2] **Time signature в паттерне** — по умолчанию из проекта; можно задать на паттерн и несколько смен внутри (Shift+Alt+T у playhead или на временном выделении, после которого возвращается размер по умолчанию).
- [P2] **Time signature влияет только на сетку и сильную долю метронома**, не на звук; меняется сразу для всех каналов паттерна.
- [P3] **Перетаскивание маркера размера** — позволяет делать неполные такты.
- [P2] **PPQ проекта (F11)** — разрешение времени в тиках; по умолчанию 96; понижение посреди проекта может сдвинуть ноты.
- [P3] **Time segments** — фоновое чередование заливки каждые N тактов (по умолчанию 4).
- [P3] **Grid color / Grid contrast / Invert grid** — цвет, контраст (High/Medium/Low) и инверсия линий сетки.
- [P3] **Pattern length marker** — Time marker типа Pattern length задаёт длину паттерна.

## 3. Масштаб и навигация

- [P1] **Page Up / Page Down** — горизонтальный zoom относительно курсора.
- [P1] **СКМ + протяжка** — прокрутка по обеим осям одновременно.
- [P1] **Вертикальный zoom** — СКМ-протяжка по клавиатуре (центр — нота под курсором) или края ползунков прокрутки.
- [P1] **Колесо мыши** — прокрутка и zoom *(точные назначения колеса без модификаторов в просмотренных страницах не описаны — unverified)*.
- [P1] **Target channel** — список в заголовке выбирает редактируемый канал паттерна; каналы с нотами отмечены; колесо — только каналы с нотами, Ctrl+колесо — все; ПКМ открывает окно инструмента.
- [P2] **Left-Shift + ПКМ-протяжка** — прокрутка вида.
- [P2] **Ctrl + ПКМ-рамка** — zoom на область в любом инструменте.
- [P2] **Shift+1/2/3** — три готовых уровня zoom; **Shift+4** — показать всё; **Shift+5** — zoom на временное выделение.
- [P2] **ПКМ-протяжка по полосам прокрутки** — прокрутка сразу в двух осях.
- [P2] **Auto zoom** — при открытии масштаб подгоняется под ноты (заглушённые ноты тоже учитываются).
- [P2] **Center (Shift+0)** — держать playhead по центру при воспроизведении.
- [P2] **Mini piano roll preview** — миниатюра нот на полосе прокрутки.
- [P2] **G/K, H/J** — переход на канал выше/ниже; H/J — на ближайший канал с нотами.
- [P2] **Auto locate channel** — при смене паттерна автоматически открывается первый канал с нотами.
- [P2] **Открытие из Playlist** — двойной клик по Pattern clip; опция Adjust start time делает время piano roll относительным к месту клика.
- [P2] **Splitter нижней панели** — перетаскивание меняет высоту, ПКМ сбрасывает; Shift+Enter показывает/скрывает панель; Swap panels меняет панели местами.
- [P3] **СКМ-клик** — полностью отдалить (жест из General settings).
- [P3] **Incremental scrolling** — клик по пустой части полосы прокрутки двигает вид плавно, а не скачком.
- [P3] **Detached** — открепить окно (например, на второй монитор).
- [P3] **Multi-touch** — двойной тап ставит ноту, два пальца прокручивают, щипок — zoom, поворот двумя пальцами — вертикальный zoom, тап двумя пальцами — показать всё.

## 4. Свойства ноты

### 4.1 Набор свойств (по Python API piano roll и разделу Note properties)
| Свойство | Смысл | Диапазон / по умолчанию | Приоритет |
|---|---|---|---|
| Pitch | номер ноты | 0…131 | [P1] |
| Time / Length | начало и длина | целые тики PPQ | [P1] |
| Velocity | сила нажатия | 0…1, по умолчанию 0.8 (MIDI 127 = 1.0) | [P1] |
| Release velocity | скорость отпускания | 0…1; реагируют не все инструменты | [P2] |
| Pan | панорама ноты | 0…1, центр 0.5 | [P2] |
| Mod X | у родных инструментов — срез фильтра канала | 0…1, по умолчанию 0.5 | [P2] |
| Mod Y | у родных инструментов — резонанс фильтра | 0…1, по умолчанию 0.5 | [P2] |
| Fine pitch | точная подстройка ноты | −120…+120 (в API — десятые доли полутона) | [P2] |
| Color | цветовая группа = MIDI-канал | 0…15 (16 групп) | [P2] |
| Slide | нота-глиссандо (сама не звучит) | вкл/выкл | [P2] |
| Porta | портаменто в эту ноту | вкл/выкл | [P2] |
| Muted | заглушена | вкл/выкл | [P1] |
| Group | номер группы, 0 = без группы | целое | [P2] |
| Note repeat | повтор ноты с частотой (FL 2024) | 0 = выкл, далее 1/4 … 1/64 триоль, всего 14 вариантов | [P3] |

### 4.2 Поведение
- [P2] **Note properties (двойной клик)** — ручки PAN, VEL, REL, MODX, MODY, переключатели Slide и Porta, цвет, Time (такт:шаг:тик) и Duration, кнопки Reset/Accept.
- [P2] **Диалог для выделения** — если нота входит в выделение, изменения применяются ко всем выделенным (Time при этом недоступен).
- [P1] **Alt+колесо над нотой** — меняет свойство, выбранное в нижней панели; Ctrl+Alt+колесо — точно.
- [P2] **Click-and-hold ноты + колесо** — меняет velocity (жест из настроек).
- [P3] **Note repeat** — редактируется в нижней панели *(как именно выглядит редактор — unverified)*.

### 4.3 Slide и Portamento (в FL — только для родных инструментов)
- [P2] **Slide (S)** — переключатель: новые ноты становятся slide-нотами. Slide-нота сама не звучит; она плавно ведёт высоту перекрываемой ноты того же цвета к своей высоте.
- [P2] **Время слайда** — равно длине перекрытия; если основная нота кончается раньше, слайд обрывается.
- [P2] **Слайд в аккорде** — опорной считается верхняя нота; все ноты аккорда сдвигаются на тот же интервал и остаются сдвинутыми.
- [P2] **Свойства при слайде** — у slide-ноты есть все свойства; они плавно переходят во время слайда.
- [P2] **Отображение** — slide-нота отмечена треугольником у начала.
- [P2] **Portamento (O)** — флаг у принимающей ноты: короткий переход высоты от предыдущей ноты к ней; инвертирует глобальное портаменто канала для этой ноты.
- [P2] **Связь с каналом** — режимы полифонии/слайда и gate канала влияют на slide и porta.
- [P3] **Для VST в FL** — руководство советует автоматизировать pitch канала вместо slide.

### 4.4 Цветовые группы (Note colors)
- [P2] **16 цветов** — цвет выбирается до рисования; Alt+C перекрашивает выделенные (или все) ноты в текущий цвет.
- [P2] **Цвет = MIDI-канал** — для внешних плагинов цвет задаёт MIDI-канал ноты; номер канала видно в подсказке.
- [P2] **Слайды по цветам** — slide действует только на ноты своего цвета (до 16 независимых слайдов); mono-режим канала тоже действует по цветам.
- [P3] **Палитры** — редактирование цветов (ПКМ по селектору), сохранение и загрузка пресетов палитры.
- [P3] **Специальный смысл цвета** — некоторые плагины используют цвет нот как команду (например, нарезчики сэмплов).
- [P3] **MIDI channel through** — при записи MIDI-канал входящих нот становится их цветом.

## 5. Нижняя панель: Event editor / control lane

### 5.1 Свойства нот («леденцы»)
- [P1] **Target control** — выбор, что показывать: свойство нот (Velocity, Release, Fine pitch, Pan, Mod X, Mod Y, Note repeat) или event-автоматизацию; через список, колесо над списком, Shift+F / F (цикл / следующее) или ПКМ по левой части панели.
- [P1] **Отображение** — у начала каждой ноты вертикальная линия с кружком, высота = значение.
- [P1] **Ноты с общим стартом** — «хвост» вправо показывает отдельные значения нот аккорда.
- [P1] **Свайп ЛКМ** — проведённая мышь задаёт значения всем пересечённым нотам; в FL 2025.2 улучшена реакция на быстрые свайпы, чтобы ни одна нота не пропускалась.
- [P1] **Правка только выделенных** — при наличии выделения панель меняет только выделенные ноты (так правят одну ноту аккорда).
- [P2] **Shift+ЛКМ-протяжка** — задаёт всем затронутым нотам одинаковое значение.
- [P2] **Alt+ЛКМ** — сброс свойства к значению по умолчанию.
- [P2] **ПКМ-протяжка — прямая линия (рампа) по свойствам нот** *(для event-данных подтверждено, для свойств нот — unverified)*.

### 5.2 Event-данные (автоматизация внутри паттерна)
- [P2] **Event-данные** — кривые параметров, привязанные к паттерну (а не отдельные Automation clips); записываются движением контроллеров или рисуются; значения 0…100%, видна одна кривая за раз.
- [P2] **Draw** — ЛКМ рисует от руки, ПКМ — прямой линией; snap действует; Shift фиксирует значение, Ctrl выделяет время, Alt отключает snap.
- [P3] **Paint** — то же без snap, для гладких кривых.
- [P3] **Erase** — удаление / сброс событий в выбранном диапазоне.
- [P3] **Interpolate** — ЛКМ: линейная интерполяция выбранных событий; ПКМ: сплайн.
- [P3] **Auto smoothing** — сглаживание нарисованного после отпускания мыши.
- [P3] **Insert current controller value (Ctrl+I)** — вставить текущее значение параметра в начало выделения.
- [P3] **Turn into automation clip** — превратить event-данные в Automation clip (настройка числа точек).
- [P3] **Relocate events** — режим вставки со сдвигом либо перезаписи при paste/cut *(в справке Event editor; для панели piano roll — unverified)*.
- [P3] **Import MIDI controller data** — импорт CC из MIDI-файла в event-данные.

## 6. Ghost notes и вид нескольких каналов

- [P1] **Ghost channels (Alt+V)** — ноты других каналов того же паттерна показываются приглушённо (сплошные блоки).
- [P2] **Двойной ПКМ по ghost-ноте** — переключиться на её канал.
- [P2] **Ghost channel selector** — панель выбора каналов-призраков; ПКМ по иконке: Show all / Show none.
- [P2] **Ghost notes from other Patterns (FL 2024.2)** — ноты из Pattern clips Playlist, пересекающихся по времени с открытым клипом, видны контуром; двигаются вместе с клипами; на их канал переключиться нельзя.
- [P2] **Какие клипы показывать** — пункты Ghost tracks / Ghost pattern clips в меню иконки; в Playlist ПКМ по заголовку трека → Show patterns as PR ghosts (сразу для нескольких треков).
- [P3] **Editable ghosts (Ctrl+Alt+V)** — ghost-ноты редактируются как обычные.
- [P2] **Snap = Events учитывает ghost-ноты.**
- [P3] **Background waveform (Alt+N)** — перетащенное аудио-превью отображается фоном как ориентир для выравнивания.

## 7. Лад и тональность (Scale / key helpers)

- [P2] **Snap to scale** — при включении перетаскиваемые и редактируемые ноты встают на ближайшую ступень лада; уже стоящие ноты не меняются, пока их не сдвинуть.
- [P2] **Root note + scale** — ПКМ по иконке выбирает тонику (C…B) и лад (мажор/Ionian, минор/Aeolian и др.; *полный список ладов unverified*).
- [P2] **Snap PR notes to scale** — привязка правок к ладу (удобно для импортированного MIDI).
- [P2] **Snap incoming MIDI** — живой ввод подтягивается к ладу: для всех устройств и/или для typing keyboard.
- [P2] **Scale highlighting** — подсветка рядов: Default (нет), Black notes (затемнить чёрные клавиши), Automatic (лад определяется по нотам или выделению, результат в hint bar).
- [P2] **Note grid highlights (Alt+B)** — продлить подсветку клавиш на всю сетку.
- [P2] **Key marker** — маркер смены тональности во времени (Time markers → Add key marker); хранит тонику и маску 12 ступеней.
- [P3] **Custom scales** — свои лады из файлов-партитур в папке эталонных ладов (нужен перезапуск).
- [P3] **Chord detection panel (FL 2026)** — панель называет аккорд по выделенным нотам или MIDI-входу; ноты должны перекрываться.
- [P3] **Приём транспонирования** — выделить всё и сдвинуть на полутон вверх-вниз, чтобы ноты встали в новый лад.

## 8. Аккорды и Stamp

- [P2] **Chord Stamp** — выбрать аккорд в меню Stamp, затем клик ставит его на высоте и позиции клика; учитывает snap и лад; звучит превью.
- [P2] **Only one** — после одного аккорда вернуться к обычному вводу; если выключено — штамповать многократно.
- [P2] **Категории Stamp** — Melodic chords (+ Advanced), Melodic scales (аккорды ступеней лада), Percussions (ритмические заготовки), Special (например, Slide up).
- [P3] **Automatic chord (top-down)** — кликнутая нота становится верхней, аккорд строится вниз с плавным голосоведением (FL 2026).
- [P3] **Automatic chord (bottom-up)** — подбирается уместный аккорд по области клика; кликнутая нота может не входить.
- [P3] **Вариативность** — повторный штамп в том же такте даёт другой вариант аккорда.
- [P3] **Chord Progression tool (FL 2024, ИИ)** — генерирует прогрессию в тональности; Count, Octave, Length, ползунок Conventional–Adventurous, Generate / Rework / Start over / Analyze (подбор под существующие ноты).
- [P3] **Chord Progression: правка аккорда** — Lock, Regenerate, альтернативы, проходящий аккорд, обращения, транспонирование, fixed bass, extra notes, voicing (Block/Open/Octave/Stacked), цвет.
- [P3] **Chord Progression: ввод и исполнение** — пресеты прогрессий и ритмов, ввод текстом (буквенные имена или римские цифры), Learn from MIDI input, Performance (Arp / Chop / Humanize / Bassline), Advanced (seed, температура и др.).

## 9. Инструменты меню Tools

**Общее для диалоговых инструментов:**
- [P2] **Каркас инструментов** — окно с ручками, результат сразу виден в piano roll (live preview), Reset / Accept, Accept = один шаг undo; работают с выделением или со всем, если ничего не выделено.

**Квантование и длины:**
- [P1] **Quick quantize (Ctrl+Q)** — быстро выровнять ноты по глобальному snap.
- [P1] **Quick quantize start times (Shift+Q)** — выровнять только начала нот.
- [P2] **Quantize (Alt+Q)** — квантование по groove-шаблону (линии сетки видны красным); Start time и Duration смешивают исходное и квантованное, Sensitivity — радиус захвата; режимы Quantize duration / Quantize end time / Leave duration / Leave end time; Levels смешивают свойства с шаблоном.
- [P2] **Quick legato (Ctrl+L)** — быстрый пресет Articulate: дотянуть ноты до следующих.
- [P2] **Articulate (Alt+L)** — пресеты Legato / Portato / Staccato / Ensure small gap / Just chop chords; Multiply (10–100% длины), Variation + Seed, Chop chords, Use lengths, Only with selection.
- [P2] **Quick chop (Ctrl+U)** — порезать длинные ноты на куски длиной snap.
- [P3] **Chop (Alt+U)** — нарезка по шаблону-партитуре; Time multiplier, Levels, Absolute pattern (по сетке или от начала каждой ноты), Group notes. В шаблонах цвета нот задают роли: границы нарезки, «не резать», «игнорировать октаву», длина шаблона.
- [P2] **Glue (Ctrl+G)** — склеить соприкасающиеся ноты.

**Генерация и разложение аккордов:**
- [P2] **Arpeggiate (Alt+A)** — арпеджио по шаблону (ноты шаблона — относительно опорной ноты); Pattern mode (Normal / Flip vertical / Alternate), Time multiplication (до 4× медленнее, до 8× быстрее), Range в октавах + Range pattern, Sync (Time / Block / Chord), Gate, Levels, Group notes.
- [P2] **Strum (Alt+S)** — «гитарный» разброс нот аккорда (аккорд = перекрывающиеся ноты с общим началом); Start: сдвиг времени (знак = направление) и Tension (ускорение), то же для velocity; Preserve end, Trigger ahead; End: сдвиг концов + Tension; Chop chords, Alternate direction.
- [P3] **Flam (Alt+F)** — добавляет быстрые удары перед нотами; пресеты, Time, Absolute (в абсолютном времени или от темпа), Before, Velocity, Group notes.
- [P3] **Claw machine (Alt+W)** — новый ритм удалением кусков и сдвигом границ: Period, Trash every, Time distortion, Remove short notes, Stretch to compensate.

**Высота и форма:**
- [P3] **Limit (Alt+K)** — уложить ноты в диапазон клавиш, перенося октавами: Key/scale, Snap (вверх / вниз / поочерёдно для нот вне лада), Wrap to top/bottom, диапазон — протяжкой по линейке над клавиатурой, тоника — кликом по клавише.
- [P3] **Flip (Alt+Y)** — Flip horizontally (разворот во времени, опция Preserve start times) и Flip vertically (зеркально по высоте).

**Уровни и случайность:**
- [P2] **Randomize (Alt+R)** — секция Pattern (генерация нот): Octave, Range, Key, Scale, Length, Variation, Population, Stack, Random portamento, Merge same notes, Seed; секция Levels: ручка на каждое свойство (−100…100%), Reset before processing, Bipolar, Seed. Главное применение — «очеловечить» velocity.
- [P2] **Scale levels (Alt+X)** — пересчёт значений свойства (например velocity) у выделения: Center, Tension (логарифм/экспонента), Multiply 0–200%, Offset −100…100.
- [P3] **LFO (Alt+O)** — рисует LFO-кривую в нижней панели на выделенном диапазоне (или в первом такте): Start Value/Range/Speed (ПКМ — темповые значения), End-секция для плавного перехода, форма sine/triangle/square, Phase.

**Генераторы и скрипты:**
- [P3] **Riff machine (Alt+E; СКМ по иконке Tools)** — 8 включаемых шагов: Note progression, Chord progression, Arpeggiation, Mirroring, Levels & panning, Articulation, Groove, Fit; Preview up to step, Work on existing score, Length, Start over, Throw dice, Accept.
- [P3] **Generate chord progression (Alt+P; ПКМ по иконке Tools)** — см. раздел 8.
- [P3] **Script… / Run last script again (Ctrl+Alt+Y) / Script list** — Python-скрипты с доступом к нотам и маркерам; окно с ручками строится из описания скрипта и пересчитывает результат при каждом движении ручки; скрипт можно запустить перетаскиванием файла; встроенный ИИ-помощник Gopher пишет скрипты по запросу.
- [P2] **Stamp** — тот же Chord Stamp (раздел 8), доступный из меню.

## 10. Буфер обмена, дублирование, преобразования

- [P1] **Cut / Copy / Paste (Ctrl+X / C / V)** — вставка идёт от самого левого видимого такта.
- [P1] **Duplicate (Ctrl+B)** — копия выделения ставится сразу справа; без выделения дублируется всё; при временном выделении шаг повтора = его длина.
- [P1] **Delete (Del)** — удаляет выделенное; без выделения удаляет всё (ноты, слайды, события).
- [P1] **Transpose** — Shift+↑/↓ на полутон, Ctrl+↑/↓ на октаву.

- [P2] **Shift left/right, Rotate left/right** — сдвиг на шаг snap и циклический сдвиг (раздел 1.6).
- [P2] **Discard lengths (Shift+D)** — укоротить ноты до минимальной длины snap.
- [P2] **Insert space / Delete space (Ctrl+Ins / Ctrl+Del)** — вставить или удалить пустое время размером с временное выделение, сдвигая всё последующее.
- [P3] **Slice & insert space (Ctrl+Alt+Ins)** — разрезать ноты в начале выделения и вставить пустое место.
- [P3] **Trim selection** — убрать ноты вне выбранного и сдвинуть оставшиеся к началу *(описание в справке неоднозначно — unverified)*.
- [P2] **Mute / Unmute selection (Alt+M / Alt+Shift+M)** — глушить или включать выделенные ноты.
- [P2] **Change color (Alt+C)** — перекрасить выделенные ноты в текущий цвет.
- [P2] **Import MIDI file (Ctrl+M)** — диалог: выбор треков и каналов, Blend with existing data, Realign events, Import time signatures, ноты с velocity 0 как note-on.
- [P2] **Export as MIDI file (Shift+Ctrl+M)** — экспорт нот piano roll в один MIDI-файл.
- [P3] **Open / Save score** — собственный формат «партитуры» FL; с FL 2026 Open score показывает и MIDI-файлы; партитуру можно перетащить из меню в браузер или в другой piano roll.
- [P3] **Copy to / Paste from MIDI clipboard (Shift+Ctrl+V)** — обмен нотами с другими секвенсорами через системный буфер.
- [P3] **Export as score sheet** — нотный лист PDF (название, размер, тональность, предпросмотр).
- [P3] **Merge pattern clips** — слить несколько паттернов (делается в Playlist).

## 11. Запись и MIDI-вход

- [P1] **Живая запись** — Record + Play пишут ноты в выбранный канал/паттерн; в Song mode после остановки создаётся Pattern clip под длину записанного.
- [P1] **Квантование ввода** — по глобальному snap (Step/Beat/Bar — да; Line/Cell/(none) — нет).
- [P1] **Typing keyboard to piano (Ctrl+T)** — компьютерная клавиатура как MIDI: тоника, октава, раскладки, snap to scale; при включении однобуквенные хоткеи не работают.
- [P1] **Preview keyboard** — клик по клавише слева проигрывает ноту канала (не во время воспроизведения).
- [P1] **Звук нот при правке** — ставимые и кликаемые ноты звучат; опция Preview notes during playback включает это и во время воспроизведения [P2].
- [P1] **Транспорт из piano roll** — Play/Pause; ПКМ во время игры — стоп и возврат к точке старта; Space / Ctrl+Space.
- [P2] **Настройки квантования записи (ПКМ по Record)** — квантовать начало, конец или оба; начало с сохранением длины; оставить длину как сыграно.
- [P2] **Recording blend** — новые ноты смешиваются с существующими, а не перезаписывают их.
- [P2] **Фильтр записи** — писать ноты и/или автоматизацию.
- [P2] **Score logger** — постоянный 3-минутный буфер всего сыгранного; Tools → Dump score log to selected pattern (сохранить случайно сыгранную идею).
- [P2] **Metronome, предотсчёт, ожидание ввода** — метроном, count-in, старт записи по первой ноте.
- [P3] **Step editing** — ввод по шагам при остановленном транспорте: длина = snap (при Line — по zoom); каждая нота двигает курсор; Numpad * — пропуск или удлинение удерживаемой ноты, Numpad / — шаг назад, sustain-педаль — пропуск.
- [P3] **Отмена записи** — Cancel current recording до остановки; после остановки — undo.
- [P3] **Playback tracking offset** — компенсация задержки начала нот при записи.
- [P3] **Play truncated notes** — при старте с середины звучат ноты, уже начавшиеся до этой точки.
- [P3] **MIDI-скрипты контроллеров** — контроллер может переключать инструменты piano roll (2025.2).

## 14. Что важно для архитектуры

- **Полный набор свойств ноты с первого дня.** Pitch, start, length, velocity, release velocity, pan, Mod X, Mod Y, fine pitch, цвет/канал (0–15), slide, porta, muted, group id, note repeat. Даже если в первой версии редактируются только velocity и mute, модель данных, формат проекта и undo должны хранить всё. Добавлять поля потом — значит мигрировать проекты.
- **Tracktion `MidiNote` этого не покрывает.** Локальная проверка `external/tracktion_engine/.../midi/tracktion_MidiNote.h`: у ноты есть только высота, начало и длина, velocity 0–127, note-off velocity, индекс цвета и mute. MIDI-канал задаётся на весь список нот (клип), а не на ноту; выразительность per-note есть только как MPE. Нужен свой слой модели нот (или расширение ValueTree своими свойствами) и свой перевод в MIDI при воспроизведении.
- **Целочисленное время в тиках с высоким PPQ.** В FL снижение PPQ сдвигает ноты. Лучше один высокий внутренний PPQ (например, 960) и целые тики, а «snap = none» ограничивать им.
- **Slide и porta — это не обычные ноты.** Slide-нота не звучит, а меняет высоту перекрытой ноты того же цвета. Это нужно вычислять при воспроизведении. Для своих инструментов — прямое управление; для VST/CLAP — pitch bend по каналу цвета или MPE / note expression. Решение о способе перевода влияет на движок воспроизведения.
- **Цвет ноты = MIDI-канал.** Канал хранится на каждой ноте. Слайды и монофония работают внутри цветовой группы. Вывод в плагин — по каналу ноты.
- **Pan / Mod X / Mod Y / fine pitch на ноте.** Для внешних плагинов нужен механизм per-note выразительности (MPE, VST3 note expression, CLAP note expressions) или явный отказ для них. Выбрать заранее.
- **Note repeat на ноте** — разворачивается в повторы при воспроизведении (данные хранят одну ноту).
- **Pattern содержит ноты нескольких каналов и event-данные.** Piano roll редактирует пару (pattern, channel). Ghost notes требуют запросов: «все каналы этого паттерна» и «все клипы в аранжировке, пересекающиеся по времени с этим клипом» с учётом смещения клипа. Нужна модель «клип ссылается на паттерн» и операция Make unique.
- **Event-данные паттерна отдельно от Automation clips**, с конвертацией между ними; общий snap и инструменты для обоих.
- **Маркеры на паттерн.** Несколько time signature, key markers (тоника + 12-битная маска лада), маркер длины паттерна, обычные именованные маркеры. Помощники лада и snap to scale должны знать лад в каждой точке времени.
- **Группы нот.** Group id в ноте; любая операция перемещения/правки должна расширять набор до всей группы; плюс глобальный переключатель, отключающий группы.
- **Транзакции undo по жестам.** Одно перетаскивание, один мазок Paint, один свайп velocity, один Accept инструмента = один шаг undo. Высокочастотные правки (свайпы, Alt+колесо) склеивать. В Tracktion — `UndoManager::beginNewTransaction` на начало жеста.
- **Инструменты как чистые функции с предпросмотром.** (исходные ноты, параметры, seed) → новые ноты. Повторный пересчёт на каждое движение ручки; Accept фиксирует, Reset/закрытие откатывает. Seed — для повторяемой случайности (Randomize, Articulate, Riff machine). Эта же схема даст API для пользовательских скриптов.
- **Правило «выделение или всё».** Почти все операции действуют на выделенные ноты, а без выделения — на все. Выделение нот, временной диапазон и диапазон высот — три независимых состояния.
- **Snap — отдельная служба.** Режимы зависят от zoom (Line), от соседних нот включая ghost (Events), от маркеров (Markers) и от глобального значения (Main). Нужен единый интерфейс «привязать позицию / длину» для мыши, инструментов и записи.
- **Шаблоны-партитуры.** Arpeggiate, Chop и Quantize используют обычные партитуры как шаблоны, а цвет нот несёт смысл. Значит, формат «сохранить/загрузить набор нот» нужен как общий механизм, а не только для импорта MIDI.
- **Различие левых и правых Shift/Alt.** В FL у Left-Shift и Right-Shift разные функции. В JUCE (`juce_ModifierKeys.h`) левый и правый модификаторы не различаются. Либо платформенный слой ввода, либо другие сочетания клавиш.
- **Однобуквенные хоткеи и typing keyboard конфликтуют.** Нужна явная модель фокуса и режима клавиатуры.
- **Предпрослушивание вне транспорта.** Клик по клавиатуре, рисование и перемещение нот должны звучать без запуска воспроизведения. Нужен путь «послать ноту в инструмент канала прямо сейчас», безопасный для аудиопотока (без блокировок и выделения памяти).
- **Score logger** — постоянный кольцевой буфер всех входящих нот, не зависящий от состояния записи.
- **Производительность на больших партитурах.** В FL исправляли медленное перемещение и выделение множества нот. Нужен пространственный индекс нот (по времени и высоте) и пакетные изменения модели.

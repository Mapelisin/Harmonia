# Пробная программа 1: JUCE + Tracktion Engine на Windows

Дата: 2026-11-08. Код: `spikes/01-engine-playback/`. Сборка: `spikes/01-engine-playback/build.cmd`.
Самопроверка: `"Harmonia Spike 01.exe" --selftest [--plugin=<путь к .vst3>] [--no-device]`,
отчёт пишется в `selftest.log` рядом с exe.

## Что проверяли

1. Собираются ли JUCE и Tracktion Engine нашими инструментами (MSVC из Visual Studio 2026, CMake, Ninja).
2. Играет ли движок MIDI-клип (4 такта аккордов Am–F–C–G, 120 BPM, по кругу) через встроенный синтезатор и сторонний VST3.
3. Работает ли живой вывод звука (ASIO / Windows Audio) и офлайн-рендер в WAV.
4. Открывается ли окно стороннего плагина.

## Находки

1. **Движок подходит.** Воспроизведение, MIDI, загрузка VST3 с окном, рендер — всё работает «из коробки». Решение №1 подтверждено.
2. **ASIO уже встроен в JUCE 9** (заголовки ASIO SDK лежат в JUCE, лицензия GPLv3). Отдельно скачивать SDK не нужно.
3. **ASIO Focusrite не стартовал.** Похоже на состояние устройства или драйвера, а не на ошибку движка:
   драйвер принимает команду старта, но не шлёт аудиоблоки. Нужно проверить вручную через окно программы
   (Audio settings → ASIO → Focusrite USB ASIO) и в Focusrite Control (источник синхронизации, частота).
   В будущей программе нужен понятный откат и сообщение пользователю — здесь он уже сделан.
4. **Гонка при запуске воспроизведения.** Если нажать Play сразу после построения проекта, движок через долю секунды
   сам останавливает воспроизведение: он асинхронно перестраивает схему обработки звука, и запрос «играть» теряется.
   Повторный Play работает. В настоящей программе нужен механизм «начать играть, когда схема готова»,
   и надо проверить смену инструмента прямо во время воспроизведения.
5. **CLAP не поддерживается** ни JUCE 9, ни Tracktion Engine. Если понадобится — писать самим. Пока откладываем.
6. **Сканирование плагинов в отдельном процессе** в Tracktion Engine есть (`EngineBehaviour::canScanPluginsOutOfProcess`).
   **Работы плагинов в отдельном процессе** (защиты от падения во время игры) нет — это делать самим (решение №5).
7. **Отрисовка:** в JUCE 9 на Windows есть рендерер Direct2D (видеокарта). Это хорошая база для быстрого piano roll — отдельно замерим.
8. **Вложенный подмодуль JUCE** в Tracktion Engine прописан через SSH-адрес. Без SSH-ключа клонировать так:
   `git -c url."https://github.com/".insteadOf="git@github.com:" submodule update --init --recursive`.
9. Встроенный 4OSC при 4 нотах с громкостью 100 доходил до 0 dBFS — у встроенных инструментов нужен запас по громкости.

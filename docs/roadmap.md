# План разработки (черновик)

Дата: 2026-11-08. Каждый этап — законченный проверяемый кусок: код, тесты, проверка скорости, документация.
После этапа — показать результат пользователю. Порядок согласуется с пользователем.

| Этап | Цель | Готово, когда |
|---|---|---|
| **M0. Каркас** | Корневой CMake, модули `core/audio/ui/app`, тесты doctest, сборка одной командой, CI на Windows. Пустое главное окно в нашей теме. | Сборка и тесты проходят локально и в CI; окно открывается. |
| **M1. Модель проекта и нот** | `core`: проект, дорожка с инструментом, MIDI-клип, `core::Note` со свойствами FL (pan, mod X/Y, fine pitch, slide…), команды и undo, сохранение/загрузка. | Тесты: создание/правка/undo/redo, сохранение → загрузка без потерь, версия формата. |
| **M2. Звук** | `audio`: выбор устройства (с понятным откатом), транспорт «играть, когда готово», загрузка VST3 с окном, предпрослушивание ноты, сканирование плагинов в отдельном процессе. | Самопроверка как в пробной программе 1 проходит; смена инструмента во время игры без сбоев. |
| **M3. Piano roll v1** | Список [P1] из `docs/research/fl-piano-roll-features.md`: инструменты Draw/Paint/Delete/Slice/Select, перемещение/растяжение/копирование, snap, масштаб и прокрутка, панель velocity, ghost-ноты, quantize, буфер обмена, транспонирование, звук при клике, undo. | Все [P1] работают и покрыты тестами; отрисовка укладывается в 60 к/с на тестовых наборах. |
| **M4. Ввод нот** | Запись с MIDI-клавиатуры, клавиатура компьютера как пианино, квантование ввода. | Запись в клип с правильным временем; тесты задержки. |
| **M5. Минимальная аранжировка** | Несколько дорожек, клипы на таймлайне, открытие клипа в piano roll (модель паттернов/клипов — по решению пользователя). | Можно собрать простой трек из нескольких инструментов и экспортировать в WAV. |
| **M6. Микшер и эффекты** | Полоска на дорожку и мастер: эффекты (встроенные и VST3), панорама, громкость, индикаторы, M/S. Окно ползунков для плагинов без своего окна. | Эффекты добавляются, переставляются, выключаются во время игры без сбоев; всё отменяется и сохраняется; слышно в экспорте. |
| **M7. Аудиоклипы** | Аудиодорожки, звуковые файлы из проводника (перетаскиванием и File → Import), волна в клипе, правка как у MIDI-клипов. | Файл слышен при игре и в экспорте; клип двигается, режется, копируется, сохраняется; пропавший файл не ломает проект. |
| **M8. Запись звука** | Готовность к записи и вход у аудиодорожки, запись с входа звуковой карты в клип, уровень входа, прослушивание. | Записанное ложится клипом с нужного места; undo; файлы в папке проекта; проверено без звуковой карты (тесты) и с ней (самопроверка). |
| **M9. Посылы** | Возвратные дорожки (Reverb, Delay, пустая) и посылы в них с полосок микшера. | Один ревер на несколько дорожек; mute/solo ведут себя как в DAW; undo, сохранение, экспорт. |
| **M10. Правка аранжировки** | Разрез клипов, копировать / вырезать / вставить клипы, предотсчёт перед записью. | Ctrl+E / C / X / V работают (и в русской раскладке), одно действие — один шаг undo; запись после предотсчёта с нужного места. |
| **M11. Автоматизация** | Панель F8: линия громкости, панорамы, посыла или любой ручки эффекта / инструмента под аранжировкой, точки мышью. | Линия слышна при игре и в экспорте; жест — один шаг undo; сохраняется; при смене темпа точки на своих долях. |
| **M12. Фейды аудиоклипов** | Фейд в начале и в конце, форма фейда, громкость клипа — ручками на клипе. | Слышно при игре и в экспорте; жест — один шаг undo; разрез сохраняет фейды у половин. |
| **M13. Темп и размер** | Темп (перетаскивание, ввод, Tap) и размер n/4 в строке транспорта. | Клипы, ноты и автоматизация остаются на долях; undo; сохраняется. |
| **M14. MIDI-файлы** | Импорт `.mid` (перетаскиванием и File → Import), экспорт клипа и всей песни в `.mid`. | Партии ложатся на дорожки, темп из файла в пустую песню; туда-обратно без потерь; один шаг undo. |
| **M15. Автосохранение** | Копия несохранённого раз в полминуты, предложение вернуть её после сбоя; надёжная запись файла. | После «падения» работа возвращается; сохранение не трогает undo; звуки находятся после переноса папки и «сохранить как». |
| **M16. Стемы** | File → Export stems: WAV на каждую дорожку (со своими эффектами и посылами, без мастера). | Стемы одной длины, вместе дают микс; соло/mute как при игре; экспорт не меняет проект. |
| **M17. Команды дорожек** | Дублировать, переставить (мышью), отрендерить дорожку в аудио. | Копия со всем содержимым, клипы не связаны; один шаг undo; рендер звучит как было. |
| **M18. Команды нот** | Легато, нарезка, склейка, сдвиг по кругу, вставить/вырезать время, меню Tools в piano roll. | Каждая команда — один шаг undo; работает на выделенном или на всём; клавиши в любой раскладке. |
| **M19. Инструменты с окном** | Strum, Arpeggiate, Humanize, Scale levels: ручки, ноты меняются сразу. | Слышно при игре; Accept — один шаг undo даже после пауз; Cancel возвращает всё. |
| **M20. Лад и аккорды** | Лад песни (подсветка рядов, привязка нот, Fit to scale), штамп аккордов. | Ноты встают на лад при рисовании и перетаскивании; аккорд одним кликом; лад сохраняется, его смена — шаг undo. |
| **M21. Последовательности аккордов** | Генератор аккордов (12 последовательностей, ритмы, бас, плавное голосоведение), определение тональности по нотам. | Alt+P пишет аккорды в пустой клип одним шагом undo; Detect угадывает до мажор / ля минор / соль мажор. |
| **M22. Цвета дорожек и клипов** | 16 цветов в меню дорожки и клипа; аранжировка, микшер и автоматизация рисуют ими. | Цвет — шаг undo, сохраняется, переживает перестановку и копирование; выделенные клипы красятся разом. |
| **M23. Повтор MIDI-клипов** | Loop в меню клипа: петля повторяется на всю длину, правится в piano roll, «запекается» в ноты. | Растянутый клип звучит повторами; разрез, сдвиг начала, запись и экспорт MIDI сохраняют звучание. |
| **M24. Маркеры песни** | Метки частей песни на линейке: добавить, переименовать, двигать, зациклить часть, Ctrl+←/→. | Метки сохраняются и отменяются; «Loop this section» играет часть по кругу. |
| **M25. Список клавиш** | F1 / кнопка «?»: все клавиши и приёмы мышью, с поиском. | Открывается и закрывается с клавиатуры; поиск находит нужное. |
| **M26. Линейка piano roll** | Маркеры песни и скобка длины повтора на линейке piano roll; Z — показать весь клип или выделенное. | Маркеры видны и кликаются; длину круга меняет мышь; Z показывает всё. |
| **M27. Браузер звуков** | F6: места и папки, прослушивание по клику и стрелкам, двойной клик или перетаскивание — в песню. | Сэмпл находится, слушается и ставится на дорожку без проводника. |
| **M28. Недавние проекты** | File → Open recent (10 последних); Z в аранжировке — вся песня или выделенное. | Проект открывается из списка в два клика; Z показывает всю песню. |
| **M29. Имена барабанов** | Клавиши и ноты подписаны по General MIDI (Kick, Snare, Hat…) на барабанных дорожках. | На дорожке «Drums» видно, какая нота какой барабан. |
| **M30. Реверс и нормализация** | В меню аудиоклипа: играть задом наперёд, поднять громкость до 0 dB. | Реверс-тарелка делается в два клика; тихая запись становится громкой. |

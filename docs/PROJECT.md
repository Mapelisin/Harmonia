# Harmonia — проектный документ

Обновлено: 2026-11-08

## Что строим

Профессиональную бесплатную DAW с открытым кодом для Windows и macOS (Apple Silicon)
с локальными ИИ-инструментами. Базовая DAW полностью работает без ИИ-моделей.

Исходное техническое задание (подготовлено ChatGPT, используется как входные данные):
`docs/original-spec.md`. Там, где оно расходится с этим документом, действует этот документ.

## Проверенные факты

Проверено 2026-11-08 по официальным источникам и новостям:

- **JUCE 9** (актуальная версия, 9.0.5) — AGPLv3 или коммерческая лицензия; JUCE 8 был так же, JUCE 7 и раньше — GPLv3.
  Заголовки ASIO SDK уже лежат внутри JUCE.
- **CLAP** не поддерживается ни JUCE 9, ни Tracktion Engine.
- **Tracktion Engine** — GPLv3 или коммерческая лицензия; лицензия JUCE нужна отдельно.
  Официальный репозиторий: https://github.com/Tracktion/tracktion_engine
- **VST3 SDK** — лицензия MIT начиная с версии 3.8 (пресс-релиз Steinberg от 29.10.2025).
- **ASIO SDK** — GPLv3 или проприетарная лицензия (октябрь 2025). Полный текст лицензии ещё не прочитан.
- **Следствие:** закрыть код Harmonia в будущем без покупки коммерческих лицензий JUCE и Tracktion будет нельзя.

Ещё не проверено:
- Vital: код под GPLv3, название — товарный знак.
- Лицензии моделей: Demucs, BS-RoFormer, модели поиска звуков по тексту.

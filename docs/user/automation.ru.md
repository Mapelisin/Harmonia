# Автоматизация — шпаргалка

[English](automation.md) | **Русский**

Автоматизация — это линия, по которой ручка дорожки сама меняется во время песни: громкость плавно
нарастает в начале, ревер прибавляется в припеве, фильтр открывается к дропу.

Панель открывается вместо piano roll: кнопка **Automation** справа над аранжировкой или **F8**
(**F7** — piano roll, **F9** — микшер).

## Как нарисовать линию

1. Кликните дорожку в аранжировке — панель показывает её. (Мастер, возвратные дорожки и группы — см.
   ниже.)
2. Слева кнопка с названием ручки (сначала **Volume**). Нажмите и выберите, что двигать:
   - **Volume**, **Pan** — громкость и панорама дорожки;
   - **Send: Reverb**… — сколько дорожка шлёт в возвратную дорожку (если они есть);
   - подменю эффектов и инструмента — любая их ручка (например, **Low-pass → Frequency**).
   Точка `•` у пункта — у этой ручки уже есть линия.
3. Справа — полоса, выровненная с тактами аранжировки над ней (прокрутка и масштаб общие).
   Кликайте по ней — появляются точки, между ними линия. Вверху полосы — максимум ручки, внизу — минимум.

| Что | Как |
|---|---|
| Клик по пустому месту | Новая точка (по сетке аранжировки, Snap); не отпуская — тянуть |
| Alt + клик / тянуть | Без сетки |
| Тянуть точку | Двигать (не дальше соседних точек) |
| Shift + тянуть точку | Только вверх-вниз, такт не меняется |
| ПКМ по точке, двойной клик | Удалить точку |
| ПКМ и вести по точкам | Удалить все, по которым прошли |
| Тянуть кружок посередине отрезка | Выгнуть линию между двумя точками |
| Двойной клик или ПКМ по кружку | Снова прямая |
| **Ctrl** + рамка | Выделить точки (**Ctrl+Shift** — добавить к выделенным) |
| **Ctrl** + клик по точке | Взять её в выделение или убрать из него |
| Тянуть одну из выделенных точек | Двигаются все вместе |
| **Del** / **Ctrl+C** / **Ctrl+X** / **Ctrl+V** | Удалить, копировать, вырезать выделенные / вставить у курсора воспроизведения |
| **Ctrl+A** / **Esc** | Выделить все точки / снять выделение |
| **Clear** | Убрать всю линию у этой ручки |

Над точкой под мышкой видно значение («-6.0 dB · bar 5.1»).
Каждое действие мышью — один шаг **Ctrl+Z**.

## Изогнутые линии

Между каждыми двумя точками посередине линии есть маленький кружок. Потяните его вверх или вниз — линия
выгнется: ручка сначала держит значение, а в конце быстро уходит («late», позже) или сначала быстро
уходит, а потом успокаивается («early», раньше). Кружок остаётся под мышкой; подсказка над ним говорит,
насколько линия выгнута. Двойной клик по кружку (или ПКМ) — линия снова прямая.

- Кружка нет там, где гнуть нечего: у скачка (две точки одна над другой), между двумя точками с одним
  значением и там, где две точки слишком близко на экране (приблизьте).
- Точка всегда важнее: если мышь на точке, берётся точка, а не кружок.
- Новая точка на выгнутой линии — обе половины гнутся так же.
- Что видно, то и слышно: и игра, и экспорт идут по выгнутой линии.
- Когда вы вырезаете, переносите или повторяете кусок времени, который проходит через выгнутую линию, обе
  её части сохраняют форму. Если изгиб сильный, программа сама ставит вдоль отрезанной части несколько
  точек, чтобы форма не изменилась.

## Несколько точек разом

Зажмите **Ctrl** и обведите точки рамкой: вокруг них появится кольцо, а слева написано, сколько выделено.
**Ctrl+Shift** добавляет ещё одну рамку к выделению, **Ctrl + клик** по точке берёт её в выделение или
убирает, **Ctrl + клик** по пустому месту (или **Esc**) снимает выделение, **Ctrl+A** выделяет все точки
линии.

- **Двигать:** потяните любую из выделенных точек — поедут все, форма сохранится (**Shift** — только
  вверх-вниз, **Alt** — без сетки). Когда одна из них упирается в невыделенную точку, в начало песни, в
  верх или низ, останавливаются все.
- **Del** удаляет их. **Ctrl+C** копирует, **Ctrl+X** вырезает.
- **Ctrl+V** вставляет у курсора воспроизведения (по сетке): поставьте курсор туда, где должна начаться
  фигура (клик по номерам тактов), и вставьте. Вставленные точки заменяют те, что были под ними, и остаются
  выделенными — их можно сразу подвинуть. Вставлять можно в линию другой ручки или другой дорожки: фигура
  сохраняет своё место между низом и верхом хода ручки.

Клавиши работают после клика по полосе автоматизации. Обычный клик (без Ctrl) работает как раньше и
снимает выделение.

## Мастер, возвратные дорожки и группы

Мастер, возвратные дорожки и группы — не строки аранжировки, кликнуть их там нельзя. Их линии выбираются
в самой панели: кнопка слева вверху (на ней имя дорожки) открывает список — текущая дорожка, **Master**,
каждая возвратная дорожка и каждая группа. Точка `•` — там уже есть линии.

Выберите **Master** — панель покажет ручки мастера: нарисуйте линию для **Volume**, чтобы вся песня плавно
затихла, или для ручки эффекта на мастере. Линия громкости возвратной дорожки — больше ревера в припеве;
линия группы — все барабаны тише в куплете.

Панель остаётся там, пока вы не кликнете другую дорожку в аранжировке (или не выберете **Track: …** в том
же списке).

## Как это работает

- До первой точки ручка стоит на значении первой точки, после последней — на значении последней.
  Между точками — прямая, пока вы её не выгнули (см. «Изогнутые линии»).
- Пока у ручки есть линия, во время игры её ведёт линия: двигать фейдер или ручку бесполезно — линия
  вернёт своё. Убрали линию (**Clear** или удалили последнюю точку) — ручка снова там, где её поставили.
- Без линии в панели пунктир — текущее значение ручки.
- Линия привязана к тактам: при смене темпа точки остаются на своих долях.
- Каждая дорожка помнит, какую ручку вы смотрели в панели.
- Линии сохраняются в проекте и звучат в экспорте WAV.

## Записать движение ручки «вживую»

1. Нажмите **Write** рядом с кнопкой записи (или **Ctrl+Shift+A**) — кнопка станет красной.
2. Запустите песню (Пробел).
3. Двигайте фейдер, панораму, посыл или ползунок эффекта — мышью или ручкой MIDI-контроллера
   (как привязать ручку — см. [микшер](mixer.ru.md), раздел «MIDI Learn»).
4. Отпустили — запись этой ручки закончилась, дальше линия идёт как была. Остановили песню — тоже.

Записанное появляется в линии этой ручки (F8) обычными точками: их можно править мышью.
Одно движение — один шаг **Ctrl+Z**. Выключите **Write**, когда закончили: иначе любое движение
ручки во время игры снова запишется.

Пока нельзя: записывать движение ручки эффекта на мастере (её линия рисуется мышью; фейдер мастера
записывается), изгиб в форме «S» (линия гнётся только в одну сторону), видеть линии прямо на клипах в
аранжировке.
